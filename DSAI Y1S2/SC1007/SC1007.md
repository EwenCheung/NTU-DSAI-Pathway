# SC1007: Data Structures and Algorithms

## Course Overview
This course covers fundamental data structures and algorithms essential for computer science and data science applications.

## Key Topics
- Linked Lists
- Binary Trees
- Binary Search
- Hash Tables
- Trie Data Structures

## Study Tips
- Practice implementing the data structures from scratch using the provided templates
- Complete all lab exercises multiple times to build muscle memory
- Focus on understanding the concepts thoroughly rather than memorizing solutions
- Use LeetCode to improve problem-solving skills, but prioritize course materials before exams

## Exam Preparation
- Review all lab and tutorial questions thoroughly
- Master the implementation of key data structures
- Practice algorithm questions involving combinations and sums
- Example exam question: "Return the number of lists (with at most 3 elements) that have a total sum greater than K"
  - Example: Given [1,2,3], K=4, the valid combinations would be [[1,2,3],[2,3]], so return 2
