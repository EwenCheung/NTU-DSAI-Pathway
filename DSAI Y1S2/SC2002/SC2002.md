# SC2002: Object Oriented Design & Programming

## Course Overview
This course covers object-oriented programming principles and design patterns using Java. Students learn to implement OOP concepts through practical applications.

## Project Tips
- For group projects, 1-2 experienced coders may be sufficient for implementation
- Ensure you have team members who will thoroughly review logic flow and design
- Code reviews are essential to catch logic errors and improve system design
- Focus on proper OOP implementation with appropriate class structures and relationships

## Team Composition Strategy
- Balance technical skills with analytical skills
- Include members who can critically evaluate the project flow
- Assign specific roles: developers, testers, documentation specialists
- Regular communication is key to project success

## Project Reference
For a sample project implementation, refer to: [SC2002-BTO-Management-System](https://github.com/EwenCheung/SC2002-BTO-Management-System)

## Lab Exercises
The lab exercises progressively build your understanding of:
- Basic Java syntax
- Classes and objects
- Inheritance and polymorphism
- Interfaces and abstract classes
- Design patterns

## Exam Preparation
- Understand OOP concepts thoroughly: encapsulation, inheritance, polymorphism
- Practice implementing design patterns
- Review all lab exercises and ensure you can implement them independently
- Study UML diagrams and be able to translate them to code
