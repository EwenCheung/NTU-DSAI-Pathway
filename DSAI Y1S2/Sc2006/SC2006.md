# SC2006: Software Engineering

## Course Overview
This course focuses on software engineering principles, methodologies, and practices for designing and developing complex software systems.

## Project Information
- Project complexity requires strong teamwork and coding contributions
- Team selection is critical - try to form a team with reliable coders
- Reference project: [SC2006-InternLink](https://github.com/EwenCheung/SC2006-InternLink)

## Lab Exercises
- Labs are crucial for understanding course concepts
- Complete all lab exercises thoroughly
- Apply concepts learned in labs to your project

## Exam Preparation
- Use the comprehensive resource: [SC2006 Notes](https://sc2006.note.ntulily.org/#/)
- Print all pages from the resource for reference during revision
- Practice time management as the exam requires quick responses
- Focus on key concepts: software processes, UML diagrams, design patterns

## Key Topics
- Software Development Life Cycle (SDLC)
- Requirements Engineering
- Software Design Principles
- UML Diagrams (Class, Sequence, Activity)
- Software Testing Methodologies
- Project Management

## Tips for Success
- Start your project early
- Hold regular team meetings
- Document your design and implementation decisions
- Practice drawing UML diagrams quickly and accurately
