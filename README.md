# NTU-DSAI-Pathway

This repository provides resources and guidance for students in the Data Science and Artificial Intelligence (DSAI) pathway at Nanyang Technological University (NTU), Singapore.

## Overview

The collection includes course materials, notes, project references, and practical advice for navigating the DSAI curriculum. While primarily designed for DSAI students, resources here may benefit students from other programs as well.

## Repository Structure

- **DSAI Y1S1**: First semester, first year courses
- **DSAI Y1S2**: Second semester, first year courses
- **BDE**: Business and Data Engineering courses
- **ICC Mods**: Interdisciplinary Collaborative Core modules
