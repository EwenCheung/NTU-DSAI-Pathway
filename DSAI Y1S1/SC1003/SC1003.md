# SC1003: Introduction to Computational Thinking and Programming

## Course Overview
This is an introductory programming course that teaches fundamental programming concepts using Python. It focuses on developing computational thinking skills and basic programming competency.

## Learning Experience
- Relatively accessible for beginners
- Teaches fundamental programming concepts and logic
- Self-learning is highly encouraged to supplement course materials
- Regular practice is essential for skill development

## Key Topics
- Python syntax and data types
- Control structures (if-else statements, loops)
- Functions and modular programming
- Data structures (lists, dictionaries, tuples)
- File handling
- Basic algorithms
- Problem-solving techniques

## Group Work Strategy
- Groups typically work on programming projects together
- Having at least one experienced programmer in the group is beneficial
- Even with an experienced coder present, all members should participate and learn
- Knowledge sharing within the group enhances everyone's learning
- For a sample project implementation, refer to: [SC1003-Group Division](https://github.com/EwenCheung/Group-Division-Data-Analytic)

## Study Resources
- Official course materials and tutorials
- Online platforms: Codecademy, LeetCode, HackerRank
- Python documentation: [python.org](https://www.python.org/doc/)
- YouTube tutorials for visual learning
- Practice exercises beyond course requirements ( use hackerearth )

## Tips for Success
- Write code regularly, even small programs help build proficiency
- Debug your own code to understand programming errors
- Experiment with different solutions to the same problem
- Build small personal projects to apply what you've learned
- Collaborate with classmates to solve challenging problems

## Preparation for Advanced Courses
This course builds the foundation for more complex programming courses. Mastering these basics will make future courses like Data Structures and Algorithms (SC1007) much more manageable.
