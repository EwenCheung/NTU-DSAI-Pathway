# AB1202: Introduction to Statistics

## Course Overview
This course provides a foundation in statistical concepts and methods essential for data analysis and business decision-making. Topics include probability theory, distributions, regression analysis, hypothesis testing, and other statistical techniques.

## Key Topics
- Descriptive Statistics and Data Visualization
- Probability Theory and Probability Distributions
- Random Variables and Expected Values
- Sampling Distributions
- Confidence Intervals
- Hypothesis Testing
- Linear Regression and Correlation
- Multiple Regression Analysis
- Time Series Analysis
- ANOVA (Analysis of Variance)

## Study Approach
- Focus on understanding the underlying concepts rather than just memorizing formulas
- Practice applying statistical techniques to real-world business problems
- Use statistical software (R, etc.) to reinforce learning
- Create concept maps to visualize the relationships between different statistical methods
